# מחשבון מחמאות - IVR לימות המשיח (Vercel)

## מבנה הקבצים (4 קבצי קוד)

1. `api/yemot/index.js` — כל לוגיקת ה-IVR (Node.js): תפריטים, state machine,
   וכל חישובי הגימטריה/קונסטרוקציה, מועתקים 1:1 מ-`index.html`.
2. `api/yemot/transcribe.py` — תמלול הקלטת השם (Python), מותאם מהפרויקט
   הקודם, לחלוטין נפרד מקוד ה-IVR.
3. `vercel.json` — קונפיגורציית Vercel לשתי הפונקציות.
4. `package.json` — מטא-דאטה ל-Node.js.

בנוסף: `content/*.txt` (מאגרי הטקסט - **יש להחליף בתוכן האמיתי**,
לא היה כלול בקבצים שהועלו), `api/yemot/requirements.txt` (תלויות פייתון),
ו-`MESSAGES.md` (רשימת הודעות המערכת).

## פריסה ב-Vercel (דרך GitHub)

1. דחפו את התיקייה הזו לריפו GitHub.
2. חברו את הריפו ל-Vercel (New Project → Import).
3. Vercel יזהה אוטומטית את `api/yemot/index.js` כ-Node function ואת
   `api/yemot/transcribe.py` כ-Python function (בזכות ה-`requirements.txt`
   הצמוד).
4. אין צורך במשתני סביבה חובה. אופציונלי: `TRANSCRIBE_SERVICE_URL` אם
   תרצו להצביע לכתובת תמלול חיצונית שונה מברירת המחדל
   (`/api/yemot/transcribe` באותו דומיין).
5. לאחר הפריסה תקבלו כתובת כמו:
   `https://your-project.vercel.app/api/yemot/index`

## הגדרת השלוחה בימות המשיח (בכל מערכת בנפרד, ללא עריכת קוד)

בממשק הניהול של ימות, על שלוחה מסוג `type=api`:

```ini
type=api
api_link=https://your-project.vercel.app/api/yemot/index
api_add_0=token=<הטוקן המתקדם של המערכת הזו - מוגדר בהגדרות השלוחה, לא מערכת:סיסמה>
api_call_id_send=yes
api_did_send=yes
api_phone_send=yes
api_extension_send=yes
```

הקוד קורא את הטוקן שנשלח בכל בקשה (`ApiToken`/`Token`) ומזהה כל מערכת
באמצעות שילוב `ApiDID` + `ApiCallId` + הטוקן - כך שאותו קוד, ללא שום שינוי,
עובד עבור כל מספר מערכות ימות שתחברו אליו. אין טוקן קבוע-מראש בקוד.

## הזרימה

1. **תפריט ראשי**: הקשה 1 = הקלדת שם (מודול טקסט עברי של ימות), הקשה 2 =
   הקלטת שם.
2. **הקלטה** → שליחה ל-`transcribe.py` → הצגת תמלול לאישור (1=המשך,
   2=הקלטה חוזרת).
3. **בחירת מין** (זכר/נקבה).
4. **בחירת סוג תוכן** (מחמאות/ברכות/מוטיבציה/פתגמים).
5. **בחירת סוג חישוב** (גימטריה/קונסטרוקציה) → ביצוע החישוב **בדיוק** לפי
   הלוגיקה שב-`index.html` (כולל צירופי "ו" בין שתי תוצאות, מיון
   אלפביתי, טיפול באותיות שלא נמצאו במאגר).
6. **השמעת תוצאות** אחת-אחת, עם אפשרות לשמוע פירוט גימטריה מלא (אות-אות)
   לכל תוצאה, לעבור לתוצאה הבאה, או לסיים.

## הערה חשובה - מאגרי התוכן

ה-HTML המקורי טוען את הקבצים `compliments_male.txt` וכו' מהשרת שבו
מתארח האתר (`fetch(fileToLoad)`), אך קבצים אלו **לא** היו חלק מההעלאה.
יצרתי placeholders ב-`content/` - יש להחליף אותם בתוכן האמיתי (שורה אחת
לכל מחמאה/ברכה/משפט) לפני פריסה לפרודקשן.
