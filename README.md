# מחשבון מחמאות - IVR לימות המשיח (Vercel)

## מבנה הקבצים

1. `api/yemot/index.js` — כל לוגיקת ה-IVR (Node.js): תפריטים, state machine,
   כל חישובי הגימטריה/קונסטרוקציה (מועתקים 1:1 מ-`index.html`), ושליחת
   התוצאות למייל (דרך Google Apps Script).
2. `vercel.json` — קונפיגורציית Vercel לפונקציית ה-Node (**חשוב: שם הקובץ
   חייב להיות באותיות קטנות בדיוק כך - `vercel.json` - אחרת Vercel לא
   מזהה אותו כקובץ קונפיגורציה כלל**).
3. `package.json` — מטא-דאטה ל-Node.js.
4. `google-apps-script/Code.gs` + `google-apps-script/DEPLOY.md` — קובץ
   ה-Google Apps Script לשליחת מיילים ומדריך פריסה מלא (ר' סעיף "שליחת
   תוצאות למייל" למטה).

בנוסף: `content/*.txt` (מאגרי הטקסט - **יש להחליף בתוכן האמיתי**,
לא היה כלול בקבצים שהועלו), ו-`Messages.md` (רשימת הודעות המערכת).

## שליחת תוצאות למייל

בתפריט שאחרי כל תוצאה ניתן להקיש 3 לשליחת **כל** התוצאות (כולל פירוט
גימטריה לכל תוצאה, במצב חישוב גימטריה) לכתובת מייל. כתובת המייל
מוקלדת ע"י המתקשר באמצעות מודול הקלדת הטקסט של ימות במצב
`EmailKeyboard`. השליחה בפועל מתבצעת דרך Google Apps Script (ולא דרך
שירות SMTP חיצוני) - ר' `google-apps-script/DEPLOY.md` להוראות פריסה
מלאות. יש להגדיר ב-Vercel את משתני הסביבה `GOOGLE_SCRIPT_URL` ו-
`MAIL_SHARED_SECRET` (ר' שם). שם השולח שיוצג לנמען הוא "מערכת מחשבון
מחמאות", גם אם כתובת המייל בפועל היא כתובת ה-Gmail של המפעיל.

## פריסה ב-Vercel (דרך GitHub)

1. דחפו את התיקייה הזו לריפו GitHub.
2. חברו את הריפו ל-Vercel (New Project → Import).
3. Vercel יזהה אוטומטית את `api/yemot/index.js` כ-Node function.
4. משתני סביבה: `GOOGLE_SCRIPT_URL` ו-`MAIL_SHARED_SECRET` **חובה** רק אם
   רוצים שתעבוד שליחת תוצאות למייל (ר' `google-apps-script/DEPLOY.md`).
   אופציונלי: `TRANSCRIBE_SERVICE_URL` אם תרצו להצביע לכתובת תמלול
   חיצונית שונה מברירת המחדל (`/api/yemot/transcribe.py` באותו דומיין).
5. לאחר הפריסה תקבלו כתובת כמו:
   `https://your-project.vercel.app/api/yemot/index`

## הגדרת השלוחה בימות המשיח (בכל מערכת בנפרד, ללא עריכת קוד)

בממשק הניהול של ימות, על שלוחה מסוג `type=api`:

```ini
type=api
api_link=https://gematria-tool-ivr.vercel.app/api/yemot/index
api_call_id_send=yes
api_did_send=yes
api_phone_send=yes
api_extension_send=yes
```

אין צורך בטוקן מערכת, כי השלוחה אינה מורידה הקלטות ואינה קוראת ל-API הניהולי של ימות.
ה-state נשמר לפי שילוב `ApiDID` + `ApiCallId`, כך שאותו קוד עובד עבור כל מספר
מערכות ימות שתחברו אליו ללא עריכת קוד.

## הזרימה

1. **כניסה לשלוחה** → מעבר מיידי להקלדת שם במודול הטקסט העברי של ימות (`HebrewKeyboard`).
2. **בחירת מין** (זכר/נקבה).
3. **בחירת סוג תוכן** (מחמאות/ברכות/מוטיבציה/פתגמים).
4. **בחירת סוג חישוב** (גימטריה/קונסטרוקציה) → ביצוע החישוב **בדיוק** לפי
   הלוגיקה שב-`index.html` (כולל צירופי "ו" בין שתי תוצאות, מיון
   אלפביתי, טיפול באותיות שלא נמצאו במאגר).
5. **השמעת תוצאות** אחת-אחת, עם אפשרות לשמוע פירוט גימטריה מלא (אות-אות)
   לכל תוצאה, לחזור לתוצאה הקודמת במקש 7, לעבור לתוצאה הבאה במקש 9, או לסיים במקש 0.
   לכל תוצאה, לעבור לתוצאה הבאה, או לסיים.

## הערה חשובה - מאגרי התוכן

ה-HTML המקורי טוען את הקבצים `compliments_male.txt` וכו' מהשרת שבו
מתארח האתר (`fetch(fileToLoad)`), אך קבצים אלו **לא** היו חלק מההעלאה.
יצרתי placeholders ב-`content/` - יש להחליף אותם בתוכן האמיתי (שורה אחת
לכל מחמאה/ברכה/משפט) לפני פריסה לפרודקשן.
